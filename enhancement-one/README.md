# Enhancement One: Software Design and Engineering

## CS 465 Travlr Getaways

This artifact demonstrates software design and engineering improvements to the Travlr Getaways full-stack application. The enhancement adds stronger input validation, authentication and role-based authorization, secure API behavior, customer inquiry management, improved error handling, and expanded automated testing.

The complete submission package includes:

- Original source code
- Enhanced source code
- Software design document
- Enhancement narrative
- Before-and-after screenshots
- Unit and integration test evidence
- Evidence index and supporting documentation
