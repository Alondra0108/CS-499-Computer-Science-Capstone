Software Design and Engineering

CS 465 Travlr Getaways

The enhanced full-stack application adds a complete customer-inquiry workflow and administrative inquiry management. It strengthens client- and server-side validation, authentication and role-based authorization, protected API behavior, error handling, data consistency, and automated testing.

Customers can search and filter trips, submit validated inquiries, and receive reference numbers. Authenticated administrators can review inquiries, filter them by status, and update their progress. The supporting design document and narrative explain the implemented changes, testing results, design decisions, trade-offs, and connections to the CS 499 outcomes.
