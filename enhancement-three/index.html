Enhancement Three

Databases

CS 340 Grazioso Salvare Dashboard

The enhanced Python and MongoDB application moves pagination, deterministic sorting, counting, aggregation, and indexed retrieval into the database layer. Query fields and operators are allow-listed at the data-access boundary, errors are translated safely, credentials are environment-based, and destructive operations include safeguards.

The user interface validates presentation-specific input, including filter syntax and map coordinates. The data-access layer remains the authoritative security boundary for database requests, while MongoDB performs the data-intensive operations. This layered design improves security, reliability, maintainability, and performance.

Evidence includes twelve passing automated tests, dashboard views for rescue categories, and before-and-after MongoDB execution statistics supporting the index decision and its storage and write-maintenance trade-offs.
