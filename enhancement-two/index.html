Enhancement Two

Algorithms and Data Structures

CS 300 Course Planning Assistant

The enhanced C++ application combines a custom hash table with a directed prerequisite graph. Kahn's topological-sort algorithm uses an adjacency list, incoming-edge counts, and a queue to generate a course order in which each prerequisite appears before its dependent courses.

Graph construction and traversal require O(V + E) time and O(V + E) additional space, where V is the number of courses and E is the number of prerequisite relationships.

The enhancement also provides line-specific validation for malformed records, duplicate courses, repeated prerequisite relationships, missing prerequisites, self-dependencies, and circular dependencies. Strict compilation and sanitizer testing provide evidence of implementation quality and runtime safety.
